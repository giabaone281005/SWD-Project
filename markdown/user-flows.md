# User Flows

## Owner/Admin Flow
1. Login
2. Access dashboard
3. Manage rooms
4. Manage tenants
5. Create contracts
6. Generate bills
7. Track payments
8. Send notifications
9. View reports

## Tenant Flow
1. Login
2. View room information
3. View contract
4. View bills
5. Pay bills
6. Submit maintenance requests
7. Receive notifications
