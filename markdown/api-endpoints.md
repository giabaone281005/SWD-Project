# API Endpoints

## Auth
```http
POST /api/auth/login
POST /api/auth/register
```

## Rooms
```http
GET /api/rooms
POST /api/rooms
PUT /api/rooms/{id}
DELETE /api/rooms/{id}
```

## Contracts
```http
POST /api/contracts
GET /api/contracts/{id}
```

## Bills
```http
GET /api/bills
POST /api/bills/generate
```
